新闻先去重成「事件」

同一件事常被十几家媒体转载。若每则各算一次，等于把一件事放大成十几件事，负面事件尤其会被高估。 系统先把标题正规化（去来源后缀、去全角与标点），再用字元 bigram 相似度分群：

  • 相似度 ≥ 0.52：视为同一篇转述；
  • 同一天 + 相似度 ≥ 0.42：同一事件的不同标题；
  • 同一天 + 点名同两位候选人 + 都是民调报道 + 相似度 ≥ 0.18：同一场民调被各家写成不同标题。

分群后舆情（情感、声量、议题）只按每群的代表计一次，界面上显示为「N 个事件」， 列表里标注「N 家媒体」。

新闻影响分怎么计算

“新闻影响”表示这则新闻在处理时应当占多大分量，范围是 0～1；它不是候选人胜率，也不是支持度。计算时会考虑是否为独家或重大消息、标题信息量，以及报道语气有多强：

新闻影响 = 0.35 + 0.15 × 重大关键词数 + min(0.25, 标题字数 ÷ 200) + 0.20 × |情感分|

结果最低为 0.05、最高为 1。重大关键词包括“独家、爆料、重大、确认、正式、宣布、民调、翻盘、丑闻”等。

举例：一则标题 25 个字、出现一次“独家”、情感分为 +0.40 的新闻，影响分为：
0.35 + 0.15×1 + 25÷200 + 0.20×0.40 = 0.705
因此它在舆情汇总中约占满权重新闻的 71%。后续计算候选人舆情时，还会再乘上“时间越久权重越低”的时效系数。

综合胜率怎么计算：程序提供高质量基准，AI统一给出最终胜率

程序先计算基础胜率，AI再统一给出最终胜率。程序先检查民调份数、新鲜度、有效样本、委托方和媒体倾向，再检查市场成交、流动性、盘口深度和价差，形成合计100%的基础胜率。

市场赔率始终是第一锚点。成交量大、流动性高、盘口深时，市场权重可达75%至90%；市场质量一般时约62%至90%；盘口较薄时市场仍保持至少55%，但不能把市场高概率直接当成最终结论。新鲜、多来源民调用于校正，权重通常10%至45%，且不会超过市场。

预测层级计算方式作用
市场主锚权重55%至90%始终为主依据；成交、流动性、盘口越强，市场权重越高
民调校正权重10%至45%越新鲜、来源越多、样本越完整且越反阵营利益，权重越高
新闻舆情只能小幅修正新闻多或负面多都不自动等于胜率大幅变化
AI统一胜率每人最多偏离基准±5个百分点综合全部因素给出最终胜率；缺市场或民调时降低置信度

AI可以修正基础胜率，但程序会限制每位候选人最多偏离基准±5个百分点。最终百分比统一保留一位小数，并用最大余数法分配尾差，保证每个县市所有正式候选人精确合计100.0%。

热点议题评分示例

“选情影响”可以理解为“这件事有多像会进入竞选讨论的具体政策事件”。当前公式为：

选情影响 = 0.45×政策强度 + 0.27×新闻影响 + 0.16×媒体覆盖 + 0.12×中间选民关联度

  • 政策强度：出现且命中的具体政策词越多、越完整，分数越高。
  • 媒体覆盖：同一事件被越多家媒体报道，分数越高；按对数计算，因此从1家变2家的影响大于从20家变21家。
  • 中间选民关联度：出现“物价、房价、薪资、就业、育儿、托育、长照、交通、治安、停电、治水”等日常议题时提高。
  • 综合排序：0.65×选情影响 + 0.35×基础热度；基础热度由新闻影响、媒体覆盖和关联候选人/县市数量组成。

例如一件住房政策事件的政策强度为 0.8、新闻影响 0.7、媒体覆盖 0.6、中间选民关联 0.9，则选情影响约为 0.45×0.8 + 0.27×0.7 + 0.16×0.6 + 0.12×0.9 = 0.763，系统会标为“可能改变选情”。这只表示值得优先阅读，不表示该政策一定改变投票结果。

党派相对得失只在同一事件同时识别到国民党和民进党候选人时计算。两党候选人的平均情感差达到 0.06 以上，才标记一方“相对有利”、另一方“相对不利”；差距更小时不强行判断。

名词解释

名词白话解释
事件多家媒体对同一件事的报道合并后形成的一条记录。例如十家媒体转载同一场造势活动，只算一个事件。
代表事件一个事件组中选出一篇作为统计入口，避免转载数量把同一件事重复放大。
字元 bigram把标题中每两个相邻汉字作为一个片段，例如“新北市长”会拆成“新北、北市、市长”等，用来比较两条标题是否在说同一件事。
加权不是每份资料都同样重要。新近、样本大、来源可靠的资料乘较大的系数，较旧或不可靠的资料乘较小系数。
有效样本考虑来源、时效和层级后得到的“等效份量”，不是单纯把调查人数相加。数值越高，民调修正力度越大。
半衰期资料影响力降到原来一半所需的时间。民调半衰期为45天，表示45天后权重变50%，90天后变25%。
归一化把不同范围的分数缩放到统一范围。例如把候选人的相对分数调整为总和100%，或将新闻情感限制在-1到+1。
爆发值新文易数提供的外部热度指标，表示某标签近期相对此前上升多少；不是搜索次数，也不是支持率。

民调怎么加权

  1. 按对战组合分开。同一个县市常有「A－B」与「A－C」两组民调，混在一起平均会产生谁都没被问到的人造支持度。系统只取「候选人与市场最相符」的那一组。
  2. 排除党内初选。只问同党候选人的互比民调（或支持度加总破百）不计入对战信号。
  3. 多源一致性核验。系统按县市、对战组合、调查机构和相近日期合并同一份民调，再以原始机构报告为优先锚点比较候选支持度：相差不超过2个百分点为多源一致；2至5个百分点保留但降低权重；超过5个百分点标为数据冲突并排除出胜率；超过8个百分点直接舍弃。只有单一来源且缺少原始报告时，标为未核验并降低权重。
  4. 机构权重 × 样本量 × 来源层级 × 阵营修正 × 结果方向 × 时间衰减。修正不仅看亲蓝或亲绿，还看民调结果是否有利委托方：绿营民调显示绿营候选人领先约×0.30至0.70，显示对手领先则约×1.00至1.05；蓝营民调按相同规则反向处理。未识别阵营委托为×1.0，且所有修正都不反向篡改支持度。
  5. 机构基础权重如TVBS 1.15、联合报／中央社1.10、一般媒体0.95；系统再参考2018、2022实际命中战绩做有限加分，只有单次命中的机构不会因此获得高权重。“钜闻天下／菱传媒2.0”可关联旧“菱传媒”战绩，但仍分别标注品牌。来源层级为机构公布表1.0、新闻标题抽取0.75、只有领先幅度0.5；时间衰减半衰期为45天。
  6. 差距证据带方向。「李四川领先 6.7」「苏巧慧领先 13.1」这类只有幅度的报道会按领先者是否一致取正负号后加权，避免把方向抵消掉。
  7. 换成胜率。领先幅度不是直接当概率用，而是用历次选举的“民调领先幅度与实际结果”做回测校准（见右下）。这套校准只作用于民调领先幅度。

新闻情感分怎么来的

系统先把新闻切成句子，再用本地选举情感词、否定词和句式规则识别语气：

  • 正负词：如“领先、看好、力挺”记正面；“落后、起诉、争议、退选”记负面。
  • 否定词：如“不、未、没有、否认”，会把紧随其后的情绪方向反转或减弱。
  • 句式规则：如“领先3个百分点”“支持度下滑”“正式参选”，按完整句子判断，不只看单个词。
  • 归一化：命中词的数量会换算到 -1 至 +1，避免长新闻仅因字数多就得到更极端的分数。

例如一句“甲的支持度上升3个百分点”，会命中正面词“支持度上升”和领先幅度规则，得到偏正面的分数；若写成“甲否认贿选”，否定规则会把“贿选”的负面方向减弱，但报道本身仍有争议背景，所以不会简单等同于好消息。

候选人舆情只统计提到该候选人的句子。相关新闻很少时，系统会向所在县市总体舆情收缩：例如候选人只有 1 则新闻、县市有 12 则新闻，该候选人的专属语气不会被 1 则新闻完全决定。

这套模型的已知局限

  • 样本少。回测只有约 40 组县市样本，在 3 个百分点以内的胶着区间，历史上有超过一半是民调领先者落选，所以模型不该被读成确定性结论。
  • 市场很薄。台湾部分盘口挂单较少，价格可能被少量资金推动，因此需要同时参考民调和新闻背景。
  • 民调滞后。机构汇总表常常落后数周，所以另外从当周新闻标题抽取，但标题抽取的精度不如完整表格，权重也相应打折。
  • 机构效应未单独建模。不同委托方的民调读数系统性不同（例如新北蓝营民调与绿营民调方向相反），目前只靠机构权重与方向加权部分吸收。
  • 舆情感知是近似。当前使用中文词典与句式规则，对反讽、隐喻和复杂因果的判断能力有限。
