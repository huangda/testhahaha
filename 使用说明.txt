台湾九合一选举 · 舆情监测系统（便携版）
==========================================

这个文件夹已经内置 Python，拷到别的 Windows 电脑后不需要安装任何东西。

怎么用
------
1) 双击「1 启动面板.bat」
   启动本地看板并自动打开浏览器（端口从 8790 起自动找空闲的）。
   关掉那个黑色窗口就等于停止服务。

2) 双击「2 更新数据.bat」
   抓取最新赔率与新闻 → 本地舆情分析 → 事件去重 → 融合预测 → 生成报告。
   需要联网；跑完再刷新看板即可看到新数据。

3) 双击「3 生成分析报道.bat」
   生成公文式分析报道、3 张数据图和 Word 版本，并自动打开浏览器。
   文件位于 data\exports\report.html、report.docx，可直接打印或另存为 PDF。

文件夹结构
----------
python\        内置的 Python 运行环境（不要删）
tem\           程序本体
web\           看板前端
config\        配置与数据源清单、民调、基线、校准曲线
data\          已抓取的数据 （已包含你目前的全部抓取结果）

改设置
------
复制 .env.example 为 .env 后可设置：
  TEM_LANG=zh-Hans  界面语言（默认简体）
  TEM_DATA_DIR      自定义数据目录

注意事项
--------
- 抓数据需要能访问 Polymarket 与 Google 新闻等站点；离线时只能查看已带的数据。
- 默认只监听 127.0.0.1（本机）。想让同局域网其他设备访问，可在此目录执行：
    python\python.exe -m tem serve --host 0.0.0.0
  该服务没有登录鉴权，不要暴露到公网。
- 默认会复制本机 .env，因此换电脑后可沿用当前 AI 配置。此文件可能含 API Key，
  不要把本便携包公开分享；需要安全包时用 -NoEnv 重新打包。

本系统为量化舆情参考工具，输出皆为模型推估，不构成投资、交易或投票建议。
